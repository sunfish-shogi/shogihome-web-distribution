# ShogiHome Web Distribution

ShogiHome のウェブ版にエンジンを組み込んでデプロイするための設定ファイルとスクリプトを管理しています。

## 注意事項

このリポジトリのコードを利用して自身のサイトにデプロイする場合、エンジンのアセットファイルを自身のドメインで公開し `engine.json` を適切に記述する必要があります。
ShogiHome の公式ドメインで管理されているアセットは CORS ヘッダーにより利用先が制限されています。

## 実行方法

### ローカル起動

```.sh
./run-local-server.sh
```

### リリースビルド

```.sh
./build.sh
```
